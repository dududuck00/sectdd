# 反馈机会与原因分析

这是对既有实验的事后分析。没有新增模型调用，没有覆盖原始分数；原因标签来自代码与日志检查，未声称独立人工评审。

## 主要结果
- 新反馈实验：初始安全失败 50 例中，联合成功 4→10；初始安全通过 150 例中，99→97。
- 原始两个胜例仅改变拒绝状态码 400→500；排除整项任务后，联合差值为 +1.05 个百分点。
- 外部 16 次功能退化：6 次响应提取/加载失败，4 次 Unpickler 上下文管理错误，3 次模板破坏，2 次 AST 语义错误，1 次偏好字段限制过严。
- 15/16 外部退化已被最终可见功能测试发现；1 次遗漏了隐藏的 notifications 字段。
