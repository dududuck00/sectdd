# RQ revision and representation experiment status

- Paper: five unified RQs. RQ1 centers on security tests before generation: overall effect, security-test increment, then matched-information expression as an attribution control; fixed-call controls into RQ2/RQ3; upstream per-task transitions into RQ5. Designs precede results. Binary feedback is correctly described as aggregate PASS/FAIL.
- External analysis: complete, based on all 400 archived trajectories. Three contrasts × ten tasks, 300 paired transitions. M's 18 repairs: 12 functional-only, six security-only, zero dual repairs; 16 functional regressions. This is a post-hoc descriptive decomposition, not a new significance claim.
- Representation experiment: complete, 480/480 new single-call trajectories, 12 tasks × two models × five seeds × four conditions. All 24 source/prose case pairs, 48 prompts, protocol and three-contrast analysis were frozen before generation. Both checkpoints ran in BF16 on GPU 0 with unchanged budgets.
- Representation results: code minus prose is +5.00 pp with functional content, 95% task-cluster interval [-0.83, 12.50]; +3.33 pp with both contents, [-4.17, 12.50]; interaction -1.67 pp, [-10.00, 7.50]. All three Holm-adjusted p values equal 1. The 7B differences are +10.0/+8.3 pp; 14B differences are 0.0/-1.7 pp. These observations do not establish a stable code-expression advantage.
- Interpretation: fixture/helper code is identical in each code/prose pair. The experiment changes test-body representation within shared executable context, not a fully code-free prompt. Concrete inputs and assertions are matched; token length is measured rather than equated. Source/prose equivalence was checked by AI against source, not by independent human reviewers.
- Execution recovery: the first 7B pass persisted all 240 model responses, but user-namespace startup failed during scoring. Eighty infrastructure-error evaluation records were quarantined; the other tasks aborted evaluation. All 240 original responses were re-evaluated with the same outer user-namespace compatibility launch used by prior studies, preserving inner Bubblewrap isolation. No response was resampled. 14B used this launch directly. Final audit detects no infrastructure errors, verifies every final response against its persisted generation, and retains one syntax-error candidate as a failure. No output reaches the 3072-token cap; all local input counts match server usage.
- Evidence count: 8,625 trajectory records, including 480 representation and 400 security-feedback ablation trajectories. Quarantined infrastructure evaluations are not additional observations. Generation services have been stopped after completion.
- Reproduction: tools/analyze_representation_v1.py is the unchanged frozen analysis; the portable scripts/reproduce_representation.py independently recomputes the complete grid, raw-case scores, task/model rates, intervals, Holm tests, and token means. Source/prose pairs and runtime provenance are included.
- Current SALLM source has a functional/functionality marker mismatch in its legacy selection helper. Inspected archived B2 prompts include the functional tests; the new runner explicitly recognizes both markers and retains setup, teardown and helpers. No historical results were overwritten to address source drift.

Scheduling note: the protocol describes a counterbalanced fixed shuffle; the implemented schedule is a deterministic shuffle of the complete balanced grid, not a Latin-square or blocked-order counterbalance. Manuscript inference does not rely on randomized assignment.

## Security-feedback ablation (RQ2)

Complete: 400 branches from 200 archived B0 initials, 20 tasks, Qwen2.5-Coder 7B/14B, five seeds, two revisions per branch (800 new calls). Functional-only versus functional-plus-security feedback has an identical functional channel at a shared candidate state, separately capped channels, and no hidden feedback. Generation used idle GPU 0; both inference services have stopped.

F/S/J rates are 63.0/65.0/51.5% versus 60.5/66.5/53.5%. Added-channel contrasts are -2.5 pp F (95% CI [-6.0,0.5], Holm p=.75), +1.5 pp S ([-3.5,8.0], p=1), and +2.0 pp J ([-2.5,7.5], p=1). Joint wins/losses/ties: 7/3/190. Three tasks gain, two lose, fifteen tie; model J differences are -1 pp (7B) and +5 pp (14B). Relative to the initials, functional-only yields 13 J repairs and no F/J regressions; combined feedback yields 18 J repairs, one J regression, three F regressions, and three function-preserving security repairs. These observations do not establish an overall security-feedback advantage.

Execution audit verifies all 800 saved responses, message provenance, functional-channel invariance, exact local/server prompt accounting, and absence of infrastructure failures. Six candidate-load evaluation failures remain; a documented execution correction implements the frozen policy to retain them and report NOT RUN instead of aborting. Original source hashes and responses are preserved, with no resampling. No output reaches the token cap. Full task/model rates, all state transitions, costs, frozen protocol, and independent portable reproduction accompany the paper.

Presentation preference: confidence intervals are omitted from manuscript prose, figures, and supplementary tables. Pass rates, percentage-point differences, paired counts, and Holm-adjusted tests remain. Frozen statistical reports and protocols retain their original calculations for reproducibility.

Metric terminology: Pass@1 (all hidden functional tests), Secure@1 (all hidden dynamic security tests), and Secure-Pass@1 (both). Tables use F/S/J or Functional/Security/Joint. Each trajectory contributes one final candidate; @1 does not fix the number of model calls. Archived field names and statistical results remain unchanged.

Post-hoc mechanism/opportunity analysis complete: all ten security-feedback joint disagreements plus two additional functional regressions, and all 16 external functional regressions (28 unique cases). Initial-visible strata preserve all observations: security-failing initials have 4→10 joint successes out of 50; security-passing initials have 99→97 out of 150. Two wins only align HTTP rejection status; whole-task exclusion gives +1.05 pp across 190 pairs. Fifteen of 16 external functional regressions fail the final visible functional test. Source/log annotations are machine-assisted, not independent human review. Primary scores and 8,625-record total are unchanged; see docs/feedback-mechanism-analysis.md.
